# Новостной бот для Telegram-канала

Каждые 15 минут бот проверяет источники и отбирает новости по словам. Раз в час присылает в канал подборку строк вида:

```
Заголовок — https://ссылка
```

Новости о фотоконкурсах приходят со значком 📷. Источники и слова можно менять прямо из Telegram, написав боту в личку.

Работает бесплатно на GitHub Actions. Компьютер держать включённым не нужно.

## Что в папке

- `sources.txt` — источники.
- `keywords.txt` — слова для отбора новостей.
- `contests.txt` — фотоконкурсы о природе и животных.
- `published.txt` — заголовки ваших материалов. По ним сводка подсказывает, писали ли вы уже о похожем.
- `bot.py` — сам бот. Трогать не нужно.
- `requirements.txt` — список библиотек для бота. Трогать не нужно.
- `.github/workflows/main.yml` — расписание запусков.

## Настройка, один раз

### 1. Бот в канале

Бот должен быть администратором канала с правом публиковать сообщения: настройки канала → Администраторы.

### 2. ID канала

- Канал публичный: ID — это `@имя_канала`.
- Канал закрытый: опубликуйте в канале любое сообщение, откройте в браузере `https://api.telegram.org/botТОКЕН/getUpdates` (вместо ТОКЕН — токен бота от BotFather) и найдите `"chat":{"id":-100...`. Число вместе с минусом и есть ID.

### 3. Репозиторий

1. На github.com справа вверху «+» → **New repository**.
2. Имя любое, отметьте **Public**. README, .gitignore и лицензию не добавляйте. **Create repository**.
3. Нажмите ссылку **uploading an existing file**.
4. Откройте распакованную папку `newsbot` и перетащите в браузер **всё её содержимое**, включая скрытую папку `.github`. На Mac скрытые файлы показывает сочетание `Cmd + Shift + .` в Finder.
5. **Commit changes**.

Проверка: на главной странице репозитория 7 пунктов: `.github`, `README.md`, `bot.py`, `contests.txt`, `keywords.txt`, `requirements.txt`, `sources.txt`.

Почему открытый: GitHub бесплатно даёт закрытым репозиториям 2000 минут работы в месяц, а бот при запуске каждые 15 минут тратит около 3000. Открытым репозиториям минуты не ограничены. Посторонние смогут увидеть списки источников и слов, токены при этом остаются скрытыми.

### 4. Секреты

**Settings → Secrets and variables → Actions → New repository secret**:

| Name | Secret |
|---|---|
| `TELEGRAM_TOKEN` | API-токен бота от BotFather |
| `CHANNEL_ID` | `@имя_канала` или `-100...` |
| `VK_TOKEN` | по желанию: сервисный ключ ВКонтакте. Без него группы ВК пропускаются |

### 5. Проверка источников

**Actions → Новости в канал → Run workflow** → галочка **Только проверить источники** → **Run workflow**. В логе шага «Проверить источники» видно по каждому источнику: `OK` или `ОШИБКА` с причиной.

### 6. Запуск

**Run workflow** без галочки. Дальше бот работает сам.

В первый раз бот не присылает старое. Из RSS и Telegram он берёт новости только за последние 2 часа, а то, что уже лежит на страницах сайтов, просто запоминает. Так же он ведёт себя с каждым новым источником.

### 7. Управление через Telegram

Найдите своего бота в Telegram, откройте с ним чат и нажмите **Start**. Бот ответит списком команд. Слушается он только администраторов канала.

Отвечает бот не сразу, а при следующем запуске, то есть в течение 15 минут.

**Добавить источник** — пришлите боту ссылку. Бот сам проверит источник и ответит, получилось ли:

```
https://site.ru/rss
https://t.me/имя_канала
+ https://site.ru/ecology
📷 https://photo-site.com/feed
```

- без значка — источник идёт через фильтр по словам;
- `+` перед ссылкой — брать из источника всё;
- `📷` перед ссылкой — брать только фотоконкурсы;
- можно прислать несколько ссылок, каждую с новой строки;
- можно просто переслать боту пост из открытого Telegram-канала.

**Другие команды:**

- `/удалить ссылка` — убрать источник
- `/источники` — показать все источники
- `/слово корень` — добавить слово в фильтр, например `/слово заповедн`
- `/минус слово` — исключение: новости с этим словом не придут
- `/убрать слово` — удалить слово или исключение
- `/слова` — показать слова фильтра
- `/сводка` — сводка за последние сутки
- `/помощь` — список команд

Всё, что вы добавили через бота, попадает в конец `sources.txt` и `keywords.txt` в репозитории.

## Сводка за сутки

Каждый день после 10:00 по Москве бот присылает в канал сводку: до 5 тем, о которых за последние сутки писали чаще всего.

Как бот находит темы:
- берёт все новости за сутки, прошедшие фильтр, вместе с повторами из разных изданий;
- ищет слова, которые чаще всего встречаются в заголовках разных изданий, например «медведи» или «мазут». Общие слова вроде «природа», «учёные», «эксперт» не считаются;
- тема наверху та, о которой написало больше разных изданий. Если о чём-то написало только одно издание, это не тема.

По каждой теме в сводке: главный заголовок со ссылкой, ещё пара заголовков, какие издания писали и был ли у вас похожий материал. Огоньки показывают, сколько изданий написали о теме: 🔥 — 2–3, 🔥🔥 — 4–5, 🔥🔥🔥 — 6 и больше.

Сводку за последние сутки можно получить в любой момент: напишите боту `/сводка`.

### Пересказ тем нейросетью (по желанию)

Если подключить GigaChat, сводка будет написана словами: «Про медведей — как они выходят к людям, нападение на грибника, прогнозы экспертов» и оценка «Для нас: интересно — …». Без ключа сводка собирается по словам и показывает заголовки.

1. Зайдите на developers.sber.ru/studio через Сбер ID.
2. **Создать проект** → раздел **AI-модели** → **GigaChat API**. Введите любое название, примите соглашение.
3. В проекте слева **Настройки API** → **Получить ключ**. Скопируйте **Authorization key**. Scope должен быть `GIGACHAT_API_PERS`.
4. На GitHub: **Settings → Secrets and variables → Actions → New repository secret**. Name: `GIGACHAT_KEY`, Secret: скопированный ключ.

Физлицам GigaChat бесплатен в пределах годового лимита токенов, сводке его хватает с большим запасом. Если GigaChat не ответит, сводка придёт в обычном виде, без пересказа.

Чтобы подсказка «У нас уже было» оставалась точной, дописывайте заголовки новых материалов в конец `published.txt`, по одному на строку.

Время сводки и число тем меняются в `bot.py`: `DIGEST_HOUR` и `DIGEST_TOPICS`.

## Как устроен фильтр

### Слова (`keywords.txt`)

Новость проходит, если в заголовке есть хотя бы одно слово. Для Telegram и ВК заголовка нет, поэтому проверяется начало поста. Анонс не проверяется: некоторые ленты, например РБК, кладут туда всю статью, и в длинном тексте всегда найдётся случайное слово.

- `экологи` — слово ищется по началу: «экология», «экологичный». Пишите корень.
- `красн книг` — в фразе каждое слово ищется по началу: «Красная книга», «в Красную книгу».
- `"лиса"` — в кавычках только целое слово: «лист» и «лисичка» не пройдут.
- `-гороскоп` — минус в начале: такие новости не приходят. На источники с плюсом исключения не действуют, из них берётся всё.
- `re:...` — регулярное выражение для сложных случаев, например чтобы ловить «комары», но не фамилию «Комаров». Такие строки можно не трогать.

Регистр и ё не важны. Слишком короткий корень ловит лишнее: «лес» найдёт «лестницу», «воробь» — губернатора Воробьёва. Такие слова пишите в кавычках и перечисляйте нужные формы.

В конце файла есть исключения для криминальной хроники: кражи, мошенники, суды. Без них из общих лент приходили новости вроде «Прокуратура вернула инвалиду украденные деньги».

### Фотоконкурсы (`contests.txt`)

Новость, совпавшая со строкой из `contests.txt`, проходит из любого источника, даже без слов из `keywords.txt`, и приходит со значком 📷.

### Повторы

Одно событие пишут разные издания разными словами. Бот сравнивает заголовок с отправленными за двое суток. Если совпадает большинство значимых слов, новость считается повтором и в канал не идёт.

## Настройки в bot.py

В начале файла есть блок «Настройки»:

- `POST_EVERY_MINUTES = 60` — как часто отправлять подборку в канал.
- `ONE_MESSAGE_PER_NEWS = True` — каждая новость отдельным сообщением.
- `MERGE_SIMILAR = False` — не склеивать похожие заголовки.
- `MAX_AGE_HOURS` — насколько старые новости брать из RSS.

## Если что-то не так

- **Источник с ошибкой.** Сайт грузит новости скриптом, закрыт капчей или не пускает зарубежные серверы (GitHub работает из США). Найдите у сайта RSS или замените источник.
- **В подборке мусор.** Посмотрите, какое слово пропустило новость, и уточните его: возьмите в кавычки или добавьте исключение командой `/минус`.
- **Бот не отвечает в личке.** Подождите 15 минут. Проверьте, что вы администратор канала и что нажали Start.
- **GitHub запускает с опозданием** на 5–20 минут. Это нормально.
